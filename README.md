# SK Toolkit

SK Toolkit is a web component library built with Stencil.

## Documentation

- Component catalog: https://hincksof.github.io/sk-toolkit/
- Storybook: https://hincksof.github.io/sk-toolkit/catalog/

## Local Development

Requirements:

- Node.js 22
- npm 11

From `web-components-stencil/`:

```bash
npm start
```

Build Storybook:

```bash
npm run storybook:build
```

Build and preview the GitHub Pages site:

```bash
npm run pages:preview
```
